# Practice Exercises - Card Widget

### Exercise 1: Elevation and Colors
Create a Card widget with:
- Background color set to `Colors.teal[700]`.
- Elevation set to `12.0`.
- Shadow color set to `Colors.teal.withOpacity(0.5)`.
- A text child "Elevated Card" with 16.0 padding.

---

### Exercise 2: Border Outlined Card
Create a Card with zero elevation (flat) but with a white outline border (`side` inside `RoundedRectangleBorder`) of thickness `2.0` and border radius of `8.0`.

---

### Exercise 3: Beveled Corner Card
Use `BeveledRectangleBorder` instead of `RoundedRectangleBorder` to give the Card angular, cut corners of size `12.0`.
