# Assignment: Profile Card Layout

### Goal
Build a beautifully styled profile contact block using a `Card` layout.

### Specifications
1. **Background**: A Card widget with `elevation: 6.0` and corner radius of `16.0`.
2. **Child Layout**:
   - Use a `Padding` widget (`padding: 20.0`) inside the card.
   - Use a `Column` to stack widgets vertically.
   - Profile avatar icon (`Icons.person_pin_rounded`) with color and size constraints.
   - Name text (bold, size 20).
   - A sub-title (e.g. "Software Engineer").
   - A flat divider line (`Divider`).
   - A `Row` showing telephone and email details.
