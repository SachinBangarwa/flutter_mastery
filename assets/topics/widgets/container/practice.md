# Container Practice Exercises

Try implementing these small tasks using a `Container` widget to test your understanding of properties:

### Exercise 1: Custom Button Shape
Create a container that mimics a call-to-action button:
- Set `width` to `200` and `height` to `50`.
- Apply a gradient background using `BoxDecoration.gradient` (e.g., from orange to red).
- Add rounded corners with a `borderRadius` of `25`.
- Put a `Text` widget in the center with bold white text: `"GET STARTED"`.

---

### Exercise 2: Border and Margin
Create a square box with custom borders:
- Set dimensions to `120` width and `120` height.
- Set the background color to light grey.
- Add a solid red border of width `4`.
- Apply a margin of `20` around the outer edge.
- Put an `Icon` in the center (e.g., `Icons.star` in red color).

---

### Exercise 3: Circular Profile Image Frame
Create a frame suitable for a profile image:
- Set width and height to `100`.
- Use `BoxDecoration` with `shape: BoxShape.circle`.
- Apply a blue border of width `3.0`.
- Put a child widget inside (e.g., an icon or image) that sits perfectly inside the circular frame.
