# Practice Exercises - Text Widget

### Exercise 1: Custom Typography Styling
Create a Text widget displaying "Welcome to Flutter Mastery" with:
- Text color set to `Colors.teal`.
- Bold font weight.
- Letter spacing of `2.0`.
- Font size of `24.0`.

---

### Exercise 2: Text Shadow Box
Render a Text widget inside a container with a dark background. Apply a neon-green shadow effect to the text using the `shadows` list property in `TextStyle`.

---

### Exercise 3: Ellipsis Truncation
Create a parent `SizedBox` with a fixed width of `100.0`. Render a long paragraph string inside it and configure it so it cuts off cleanly on a single line showing an ellipsis (`...`).
