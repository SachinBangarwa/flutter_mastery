# Assignment: Mixed Text Card Layout

### Goal
Build a beautifully styled product information block using only `Text` widgets nested within standard layouts.

### Specifications
1. **Title Text**: Bold, `fontSize: 24.0`, centered, with a letter spacing of `1.0`.
2. **Price Text**: Color set to `Colors.green`, `fontSize: 18.0`, bold.
3. **Description**: Subdued gray color (`Colors.grey`), italicized font style, max lines of `3` with ellipsis truncation if it goes longer.
4. Use a `Column` with centered alignment to layout the components inside a padding container.
